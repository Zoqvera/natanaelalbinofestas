Portfólio comentado

Projetos que mostram como uma ideia se transforma em cenário.

Cada case reúne uma leitura do projeto a partir do que está visível na composição: paleta, volumes, cenografia, ritmo visual, elementos temáticos e integração dos balões. O objetivo é mostrar não apenas o resultado, mas a lógica de design por trás dele.

Como ler um projeto

O portfólio também explica o método de criação

Uma fotografia final mostra o conjunto, mas um case permite separar as decisões que formam esse conjunto. A paleta orienta a atmosfera; os volumes definem hierarquia; a cenografia organiza a narrativa; e os balões podem conectar, enquadrar ou ampliar pontos focais.

Esse tipo de conteúdo também ajuda quem está planejando uma celebração a identificar preferências com mais precisão. Em vez de pedir apenas “algo bonito”, é possível reconhecer se a intenção está mais próxima de uma composição delicada, imersiva ou vibrante.
